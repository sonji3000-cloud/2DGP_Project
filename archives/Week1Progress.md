# 1주차 작업내용

Python과 Pico2d로 피코슈타인의 기본 시제품을 만들었다. 하나의 테스트 맵에서 탑뷰와 레이캐스팅 1인칭을 오가며 이동, 조준, 사격, 장전을 할 수 있다.

| 작업 | 구현 내용 |
| --- | --- |
| 테스트 맵과 시점 전환 | 격자 맵에 벽과 고정 표적 두 개를 배치하고 플레이어의 벽 충돌을 구현했다. `Tab`으로 시점을 바꿔도 위치, 조준 방향, 탄약과 장전 상태가 이어진다. |
| 이동과 조준 | 두 시점에서 `W/S`는 전진·후진, `A/D`는 시선 기준 좌우 이동, `Q/E`는 시선 회전으로 통일했다. 탑뷰에서는 플레이어가 화면 중앙에 오고 전방이 화면 위쪽을 향하도록 맵을 회전한다. |
| 권총 발사와 명중 | `Space`로 한 발씩 발사하고, 탄이 이동한 구간에서 벽과 표적 중 먼저 닿은 대상을 판정한다. 탑뷰의 빨간 조준 레이저는 같은 판정을 사용해 첫 충돌 위치에 점을 표시한다. |
| 탄약과 장전 | 탄창 8발과 예비탄 24발로 시작하며 화면 왼쪽 아래에 잔량을 표시한다. `R`을 누르면 0.88초 동안 장전 애니메이션이 재생되고, 완료 시 탄창의 빈자리를 예비탄으로 채운다. |
| 플레이어와 표적 스프라이트 | 탑뷰에서 다리는 이동 방향을, 상체는 조준 방향을 향한다. 1인칭에는 루거 P08 스프라이트와 조준점, 보행 시 권총 흔들림을 적용했다. 두 시점의 발사·장전 프레임을 동기화했고, 고정 표적은 보병의 대기·피격 자세로 표시한다. |
| 벽과 바닥 그래픽 | 탑뷰에 석벽과 석재 바닥을 타일로 배치했다. 1인칭은 벽과 바닥에 원근을 적용하고, 벽 뒤에 있는 표적의 가려진 부분을 표시에서 제외한다. |

장전과 탄약 계산, 두 시점의 이동 방향 일치, 레이저 끝점과 탄의 충돌 위치 일치를 코드로 확인했다. 벽·바닥과 화면 회전은 창을 띄우지 않는 방식으로 렌더링해 확인했다. 이 기록의 기준 커밋은 `origin/main`에 푸시된 `bc3f5a7`이다.
