# 피코슈타인 개발 계획

Python과 Pico2d로 작은 시제품부터 만든다. 각 단계에서 게임을 실행해 완료 기준을 확인한 뒤 다음 기능을 추가한다.

## 개발 방식

- 객체 지향으로 개발한다. `Game`은 입력과 게임 루프, `World`는 맵과 플레이어·표적·탄의 상태, `Pistol`은 발사 간격과 탄의 이동·명중 처리를 맡는다.
- `TopDownRenderer`와 `FirstPersonRenderer`는 같은 `World`를 읽어 화면을 그린다. 시점 전환은 활성 렌더러와 이동 방향의 해석을 바꾼다.
- 공통 벽 검사와 좌표 계산은 함수로 재사용한다. 한국어 커밋 메시지에 각 커밋에서 바뀐 기능을 적는다.

## 1단계. 탑뷰·1인칭 전환과 권총 발사

작은 테스트 맵에서 이동하고 조준한다. 같은 위치에서 **2D 탑뷰와 3D처럼 보이는 레이캐스팅 1인칭**을 오가며 권총을 쏠 수 있게 만든다.

### 구현 순서

- [x] 바닥, 벽, 고정 표적이 있는 2D 격자 맵을 만든다. 플레이어 위치와 조준 각도는 두 시점이 공유한다.
- [x] 탑뷰에 맵과 플레이어의 조준 방향을 그린다. `WASD` 이동, `Q/E` 좌우 회전, 벽 충돌을 연결한다.
- [x] 같은 맵을 1인칭으로 그린다. 벽을 단색 세로 띠로 표시하고 `Tab`을 한 번 누를 때마다 시점을 전환한다.
- [x] 스페이스바를 누르면 현재 조준 각도로 권총 탄 한 발을 발사한다. 공통 월드에서 탄을 이동시키고, 매 프레임 이동한 구간에서 벽 또는 표적 중 먼저 닿은 쪽을 판정한다.
- [x] 두 시점에서 발사와 명중을 확인할 수 있게 간단한 표시를 넣는다. 탑뷰에서는 조준선과 탄, 1인칭에서는 화면 중앙의 조준점과 발사 표시를 사용한다. 표적의 명중 상태는 공유한다.

### 시제품 조작

| 키 | 탑뷰 | 1인칭 |
| --- | --- | --- |
| `WASD` | 화면 상하좌우 이동 | 시선 기준 전진·후진·좌우 이동 |
| `Q` / `E` | 조준 방향 좌회전 / 우회전 | 시선 좌회전 / 우회전 |
| `Space` | 조준 방향으로 권총 발사 | 화면 중앙 방향으로 권총 발사 |
| `R` | 권총 장전 | 권총 장전 |
| `Tab` | 1인칭으로 전환 | 탑뷰로 전환 |
| `Esc` | 게임 종료 | 게임 종료 |

`Tab` 전환과 1인칭의 시선 기준 이동은 시제품에서 확인할 조작안이다. 월드를 한 번 갱신한 뒤 현재 시점에 해당하는 화면을 그린다. 시점 전환 시 플레이어 위치, 각도, 진행 중인 탄과 발사 간격을 이어 간다.

### 권총 장전

- 시제품은 탄창 **8발**, 예비탄 **24발**로 시작한다. 발사할 때 탄창에서 한 발을 차감하고, 남은 탄은 화면 왼쪽 아래에 `AMMO 탄창 / 예비탄`으로 표시한다.
- 탄창에 빈자리가 있고 예비탄이 있을 때 `R`을 누르면 두 시점에서 같은 9프레임 장전 동작을 재생한다. 0.88초 뒤 빈자리만큼 예비탄을 옮긴다.
- 장전 중 이동·조준과 시점 전환은 계속 가능하다. 이미 발사한 탄은 계속 이동하며, 장전이 끝나면 다시 발사할 수 있다.

### 완료 기준

- [ ] 같은 위치에서 여러 번 시점을 바꿔도 플레이어 위치와 조준 방향이 이어진다.
- [ ] 두 시점에서 이동과 조준을 동시에 할 수 있고, 벽을 통과하지 않는다.
- [ ] 같은 위치와 각도에서 쏘면 어느 시점에서든 같은 표적을 맞힐 수 있다. 벽 뒤의 표적은 맞지 않는다.
- [ ] 발사 직후 시점을 바꿔도 이동 중인 탄이 사라지거나 발사가 중복되지 않는다.

### 실행 방법

프로젝트 폴더에서 실행한다. Pico2d 1.5.1이 설치되어 있으면 두 번째 명령부터 실행하면 된다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

시작 위치에서 조준 방향 바로 앞에 고정 표적이 있다. 표적에 맞으면 잠시 밝게 표시되고 명중 후 색상이 바뀐다. 위 완료 기준은 실제 플레이로 확인한 뒤 체크한다.

좌표계, 벽 투영, 스프라이트 가림은 [시점 전환 구현 참고](ViewRenderingNotes.md)를 참고한다.

| 5. 조정과 검증 | 시점 전환 조작감, 적 배치, 무기 수치, 그리기 성능 | 두 시점으로 한 판씩 플레이해 막히는 구간과 조작 문제를 수정한다. 여러 적과 탄이 있을 때 월드 갱신과 그리기 시간을 확인한다. |
